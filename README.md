# Static Website Package

This project is a static React SPA package with clean URLs powered by `BrowserRouter` and a PHP content-management backend for `data-store.json` / `data.js`.

## Included

- `index.html`
- `index.php` (SEO front controller for server-rendered meta tags)
- `index.css`
- `index.js`
- `App.js`
- `data-store.json` (source of truth for editable content)
- `data.js` (frontend runtime data, auto-generated by backend writes)
- `seo.js`
- `components/*.js`
- `pages/*.js`
- `backend/config.php`
- `backend/lib/DataStore.php`
- `backend/lib/SubmissionStore.php`
- `backend/api/data.php`
- `backend/api/contact-submit.php`
- `backend/api/trial-submit.php`
- `backend/api/submissions.php`
- `backend/admin.php`

## Deployment

1. Upload all files/folders to your Apache server.
2. Make sure PHP 8.0+ is installed/enabled.
3. Configure server rewrites so all non-file routes serve `index.php` (keep real file routes such as `/backend/admin.php` and `/backend/api/data.php` untouched).
4. Open the site via your domain path.

### Required Rewrite Rule

- `Nginx`: `try_files $uri $uri/ /index.php;`
- `Apache` (`.htaccess`):
  - `RewriteEngine On`
  - `RewriteCond %{REQUEST_FILENAME} !-f`
  - `RewriteCond %{REQUEST_FILENAME} !-d`
  - `RewriteRule . /index.php [L]`

Example URLs:

- `https://example.com/`
- `https://example.com/services`
- `https://example.com/portfolio/ecommerce-premium`
- `https://example.com/backend/admin.php`

## PHP Content Admin

### 1. Configure token

Edit `backend/config.php`:

```php
return [
    "admin_token" => "replace-with-a-long-random-secret-token"
];
```

### 2. File permissions

Ensure PHP can write these files/folders:

- `data-store.json`
- `data.js`
- `backend/backups/`

### 3. Admin UI

Open:

- `/backend/admin.php`

Use your token in the **Admin Token** field.  
You can then manage content in a visual dashboard (section tabs, card-based add/edit/delete, modal forms), similar to common social/CMS workflows.

### 3.1 Submission inbox in admin

The admin sidebar now includes:

- `Contact Submissions`
- `Trial Submissions`
- `Newsletter Subscriptions`

From these sections you can:

- View submission details
- Download the saved `.txt` info file
- For trial submissions, download each uploaded file
- For newsletter subscriptions, download each saved `.json` record

### 4. API endpoints

Base endpoint:

- `/backend/api/data.php`

Auth header (required):

- `X-Admin-Token: <your-token>`

#### Read entire data

```bash
curl -H "X-Admin-Token: YOUR_TOKEN" "https://example.com/backend/api/data.php"
```

#### Read a nested path

```bash
curl -H "X-Admin-Token: YOUR_TOKEN" "https://example.com/backend/api/data.php?path=services/0/title"
```

#### Add into an array (POST append)

```bash
curl -X POST "https://example.com/backend/api/data.php" ^
  -H "Content-Type: application/json" ^
  -H "X-Admin-Token: YOUR_TOKEN" ^
  -d "{\"path\":\"faq\",\"value\":{\"question\":\"New question\",\"answer\":\"New answer\"}}"
```

#### Add into an object (POST with key)

```bash
curl -X POST "https://example.com/backend/api/data.php" ^
  -H "Content-Type: application/json" ^
  -H "X-Admin-Token: YOUR_TOKEN" ^
  -d "{\"path\":\"general\",\"key\":\"phone\",\"value\":\"+1-555-0100\"}"
```

#### Replace value (PUT)

```bash
curl -X PUT "https://example.com/backend/api/data.php" ^
  -H "Content-Type: application/json" ^
  -H "X-Admin-Token: YOUR_TOKEN" ^
  -d "{\"path\":\"services/0/title\",\"value\":\"Color Correction and Matching\"}"
```

#### Remove value (DELETE)

```bash
curl -X DELETE -H "X-Admin-Token: YOUR_TOKEN" "https://example.com/backend/api/data.php?path=faq/0"
```

## Public Form Endpoints

These endpoints are used by website forms and do not require admin token:

- `POST /backend/api/contact-submit.php`
- `POST /backend/api/trial-submit.php` (multipart/form-data with `files[]`)
- `POST /backend/api/newsletter-subscribe.php`

### Contact payload fields

- `firstName` (required)
- `lastName` (required)
- `email` (required)
- `message` (required)

### Trial payload fields

- `name` (required)
- `email` (required)
- `instructions` (required)
- `files[]` (required, up to 3 files, supports images + video files)

### Newsletter payload fields

- `email` (required)
- `source` (optional, defaults to `footer`)
- `website` (optional honeypot; leave empty)

## Notes

- Every successful POST/PUT/DELETE creates a backup in `backend/backups/` and regenerates `data.js` from `data-store.json`.
- Backup directory access is denied through `backend/backups/.htaccess`.
- Form submissions are saved as separate text records under `backend/submissions/`.
- Trial uploads are saved inside per-submission folders with `info.txt` + uploaded files.
